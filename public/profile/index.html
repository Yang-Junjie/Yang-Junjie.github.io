01 / 引擎与编辑器 已归档

Luna-lite Compact Game Engine & Editor

紧凑的 C++20 游戏引擎与编辑器，包含 TinyRHI 图形抽象、OpenGL 延迟 PBR 渲染、 EnTT 场景系统、资产管线与 Lua 脚本，并提供独立运行时。

  • OpenGL 4.5
  • Lua
  • EnTT

02 / 实时光线追踪

vulchovy Real-time Path Tracer

面向研究的实时光线追踪渲染器，基于 Vulkan 1.3 硬件 ray query 与 Slang 着色器， 通过 NEE 与 MIS 实现路径追踪。支持 PBR 材质、介电透射、HDR 环境采样，以及 glTF / OBJ 场景加载。

  • C++20
  • Vulkan 1.3
  • Slang
  • Ray Query

03 / 游戏引擎

Fermion Game Engine

使用 C++20 构建的游戏引擎，包含 Boson 编辑器与 C# 脚本系统。 以 OpenGL、RenderGraph、Deferred 和 EnTT ECS 组织渲染与场景，并集成 Box2D / Jolt 的二维、三维物理模拟。

  • C++20
  • OpenGL
  • RenderGraph

04 / 图形工具

面向 Vulkan 1.3 的 C++20 轻量封装。用 RAII 管理图形资源的生命周期， 并通过 SPIR-V 反射生成描述符与顶点布局，让渲染实验更容易组织。
